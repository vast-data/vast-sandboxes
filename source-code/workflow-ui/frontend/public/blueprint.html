Runs each sub-agent as an OpenShell sandbox with OpenClaw inside. Enforces per-department egress policy, spawns via CreateSandbox, and supervises the reason / plan / tool-call loop.

Grounds agents in your corpus: embeds queries, retrieves and reranks spans from VastDB, and augments the NIM context so every finding is cited back to a source.

Telemetry plane
vastclaw-db / telemetry.spans
Every span from both writers. All metrics — latency, model, tokens, cost, tool hits, coverage, degraded flags — ride in attributes_json, so new metrics never need a schema migration.
Control plane
vastclaw-db / vastclaw_control
System of record for workflows, turns and runs, plus the versioned report PDFs and the admin audit trail — the history that outlives any pod.
Memory plane
vastclaw-db / memory_<dept>
Per-department agent long-term memory, kept separate from telemetry so recall and audit never contend for the same rows.
